## 2. 数据和模型配方

训练来源有 814 条可准入决策、2 个 run。按 seed1701、run/重复输入关联隔离固定
50 条 train 和 16 条 dev，每侧实际各 1 个 run。成员保留 occurrence、transition、来源
archive digest、run 和角色。未将不完整轨迹升级为完整局；本轮不使用真实未来或历史输入。
普通 decision 隔离作为另一个明确协议通过合成回归，实际小样仍使用 run 隔离。

S01 是 A/PF/M0/N：当前观察与每个完整候选分别联合编码，masked mean 1024，
Linear(1024,1)，1025 个可训练参数。seed1701，AdamW、lr0.001、5 epochs 的上限配置，
本次固定 max_steps100，单决策更新；不是后续十二格有效 batch32 的完整 pilot。

原 standard 小样 token p50/p95/max 为 5207.5/7947.25/8688，超过当前 pin 的 8192 上限。
第一次编码在 11 批后明确失败，用时 86.655 秒；没有截断或丢候选。新增全量长度预检。
随后固定已有 lite serializer：同样 66 条决策／358 个候选，长度 3218.5/5438.2/5983，
无超限。lite 保留 DECISION、VISIBLE_ENTITIES 和全部候选，但减少 RUN 字段、只读 lite
准入的 Reads；它是新的明确输入配方，不能称为保持所有事实的无损加速。
